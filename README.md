# AI Automation with n8n — Portfolio

Portfolio website of Ahmed Ghonamiy, an n8n automation developer.

**Contact:** ahmed287302@gmail.com · [LinkedIn](https://www.linkedin.com/in/ahmedghonamiy)

## Projects
1. **Automated Meeting Scheduling**: a webhook creates a Google Calendar event with a Meet link and emails an invitation.
2. **AI Technical Support Bot**: Hugging Face sentiment analysis routes unhappy customers to Slack and emails every customer.
3. **AI LinkedIn Content Creator**: Gemini picks a topic, writes a post in Egyptian Arabic, publishes to LinkedIn and sends a copy to Telegram.

The importable n8n workflows are in `/workflows` (credentials are not included).

## Run
Open `index.html` in a browser. It is a single self-contained file.

## Publish with GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
